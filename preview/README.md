# Preview — the same sample book at both summary levels

Open `level-2/index.html` (study edition) and `level-1/index.html` (exam-review edition) in a browser.
Both were built by `build_book.py` from the fixtures in `tests/fixtures/` (one plan, the same extractions and
the same two supplements; only the drafts differ — one draft store per level). Try the "Aa" menu (palettes,
text size) and the theme button. Every formula carries a line that says what its symbols mean, at both levels.
