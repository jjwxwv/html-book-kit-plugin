บทที่ 3

ความน่าจะเป็นเบื้องต้น

นิยามพื้นฐานของความน่าจะเป็น กฎการบวก กฎการคูณ และทฤษฎีบทของเบสสำหรับกลับทิศเงื่อนไข

3.1 การทดลองสุ่ม ปริภูมิตัวอย่าง และเหตุการณ์

การทดลองสุ่ม (random experiment)
รู้ผลลัพธ์ที่เป็นไปได้ทั้งหมด แต่บอกล่วงหน้าไม่ได้ว่าจะออกผลใด
ปริภูมิตัวอย่าง (sample space) S
เซตของผลลัพธ์ที่เป็นไปได้ทั้งหมด
เหตุการณ์ (event)
เซตย่อยของ S ที่สนใจ
ส่วนเติมเต็ม (complement) E′
เหตุการณ์ที่ E ไม่เกิด

ผลลัพธ์มีโอกาสเท่ากัน: P(E) = n(E) / n(S)

สมบัติ: 0 ≤ P(E) ≤ 1, P(S) = 1, P(E′) = 1 − P(E)

n(E), n(S) = จำนวนผลลัพธ์ใน E และในปริภูมิตัวอย่าง

ทอยลูกเต๋า 1 ลูก: S = {1, …, 6}, เลขคู่ = {2, 4, 6} → P = 3 / 6 = 0.5

3.2 กฎการบวกและกฎการคูณ

กฎการบวก (หรือ): P(A ∪ B) = P(A) + P(B) − P(A ∩ B) ลบส่วนที่นับซ้ำ

กฎการคูณ (และ): P(A ∩ B) = P(A) × P(B | A)

∪ = หรือ, ∩ = และ, P(B | A) = โอกาสของ B เมื่อรู้ว่า A เกิด

ไม่เกิดร่วมกัน (mutually exclusive)อิสระต่อกัน (independent)
ความหมายเกิดพร้อมกันไม่ได้เหตุการณ์หนึ่งไม่เปลี่ยนโอกาสของอีกเหตุการณ์
เงื่อนไขP(A ∩ B) = 0P(B | A) = P(B)
สูตรที่สั้นลงP(A ∪ B) = P(A) + P(B)P(A ∩ B) = P(A) × P(B)
ตัวอย่างทอยครั้งเดียว ได้ 1 กับได้ 6ทอยสองครั้ง ผลครั้งแรกกับครั้งที่สอง

ไพ่ 52 ใบ โพแดงหรือคิง: 13/52 + 4/52 − 1/52 = 16/52 = 4/13 (ลบคิงโพแดงที่นับซ้ำ)

ไม่เกิดร่วมกัน ≠ อิสระต่อกัน: ถ้าไม่เกิดร่วมกันและโอกาสของแต่ละเหตุการณ์มากกว่าศูนย์ รู้ว่า A เกิดก็รู้ทันทีว่า B ไม่เกิด จึงขึ้นต่อกัน

3.3 ความน่าจะเป็นแบบมีเงื่อนไขและทฤษฎีบทของเบส

ความน่าจะเป็นแบบมีเงื่อนไข (conditional probability): P(A | B) = P(A ∩ B) / P(B) เมื่อ P(B) > 0

ทฤษฎีบทของเบส (Bayes' theorem): P(A | B) = P(B | A) × P(A) / P(B)

P(B) = P(B | A) × P(A) + P(B | A′) × P(A′)

เงื่อนไข P(B) > 0 · A′ = A ไม่เกิด

ความชุก 1%, ผลบวกในผู้ป่วย 99%, ผลบวกผิดพลาด 5%: P(+) = 0.99 × 0.01 + 0.05 × 0.99 = 0.0594 → P(D | +) = 0.0099 / 0.0594 ≈ 16.7%

P(A | B) ≠ P(B | A): ผลบวกในผู้ป่วย 99% ไม่ได้แปลว่าผู้ได้ผลบวกป่วย 99% ต้องคิดความน่าจะเป็นตั้งต้น P(A) ด้วยเสมอ

prior, sens, false_pos = 0.01, 0.99, 0.05
p_pos = sens * prior + false_pos * (1 - prior)
print(round(sens * prior / p_pos, 3))   # 0.167

  • ไม่เกิดร่วมกันกับอิสระต่อกันเป็นคนละแนวคิด
  • เบสกลับทิศเงื่อนไข และต้องใช้ P(A) ตั้งต้นเสมอ
  • สมบัติพื้นฐานสามข้อของความน่าจะเป็นคืออะไร 3.1
  • เหตุใดกฎการบวกต้องลบ P(A ∩ B) 3.2
  • ไม่เกิดร่วมกันกับอิสระต่อกันต่างกันอย่างไร สูตรใดสั้นลงในแต่ละกรณี 3.2
  • เขียนทฤษฎีบทของเบสและสูตรของ P(B) 3.3
