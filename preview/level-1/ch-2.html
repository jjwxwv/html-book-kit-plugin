บทที่ 2

การสรุปข้อมูลด้วยตัวเลข

สรุปข้อมูลด้วยตัวเลขสองกลุ่มที่ต้องรายงานคู่กัน: ค่ากลางบอกตำแหน่ง ค่าการกระจายบอกความกว้าง

2.1 ค่ากลางของข้อมูล

ค่ากลาง (measure of central tendency)วิธีหาข้อสังเกต
ค่าเฉลี่ยเลขคณิต (mean)x̄ = Σxi / nใช้ข้อมูลทุกค่า ไวต่อค่าผิดปกติ
มัธยฐาน (median)ค่าตรงกลางเมื่อเรียงข้อมูล ถ้า n เป็นเลขคู่ให้เฉลี่ยสองค่าตรงกลางทนต่อค่าผิดปกติ
ฐานนิยม (mode)ค่าที่ปรากฏบ่อยที่สุดอาจมีหลายค่า หรือไม่มีเลย

xi = ข้อมูลตัวที่ i, n = จำนวนข้อมูล

6, 7, 7, 8, 22: ค่าเฉลี่ย = 50 / 5 = 10, มัธยฐาน = 7, ฐานนิยม = 7 ค่า 22 ดึงค่าเฉลี่ยขึ้นแต่ไม่กระทบมัธยฐาน

ข้อมูลมี ค่าผิดปกติ (outlier) หรือเบ้: ใช้มัธยฐานแทนค่าเฉลี่ย

2.2 การวัดการกระจาย

การวัดการกระจาย (measure of dispersion) บอกว่าข้อมูลอยู่ห่างกันเพียงใด จำเป็นเพราะค่าเฉลี่ยเท่ากันแต่การกระจายต่างกันได้ เช่น A: 9, 10, 10, 10, 11 กับ B: 2, 6, 10, 14, 18 มีค่าเฉลี่ย 10 ทั้งคู่

2.2.1 พิสัยและควอร์ไทล์

พิสัย (range)
ค่ามากสุด − ค่าน้อยสุด ใช้ข้อมูลเพียงสองค่า จึงไวต่อค่าผิดปกติ
ควอร์ไทล์ (quartile)
Q1, Q2, Q3 แบ่งข้อมูลที่เรียงแล้วเป็นสี่ส่วนเท่ากัน
พิสัยระหว่างควอร์ไทล์ (IQR)
Q3 − Q1 คือความกว้างของข้อมูลครึ่งกลาง
  1. เรียงข้อมูลจากน้อยไปมาก
  2. มัธยฐานของทั้งชุด = Q2
  3. มัธยฐานของครึ่งล่าง = Q1, ของครึ่งบน = Q3
  4. IQR = Q3 − Q1

ค่าผิดปกติ: ต่ำกว่า Q1 − 1.5 × IQR หรือสูงกว่า Q3 + 1.5 × IQR

2, 4, 5, 7, 8, 9, 12: Q1 = 4, Q2 = 7, Q3 = 9, IQR = 5, พิสัย = 10, ขอบค่าผิดปกติ −3.5 และ 16.5 จึงไม่มีค่าผิดปกติ

วิธีหาควอร์ไทล์ต่างกันได้ตามตำราหรือโปรแกรม วิธีนี้ไม่นับมัธยฐานรวมในสองครึ่งเมื่อ n เป็นเลขคี่

2.2.2 ความแปรปรวนและส่วนเบี่ยงเบนมาตรฐาน

ความแปรปรวน (variance) เฉลี่ยกำลังสองของระยะห่างจากค่าเฉลี่ย ใช้ข้อมูลทุกค่า ยกกำลังสองเพื่อไม่ให้ระยะห่างบวกและลบหักล้างกัน

ประชากร: σ2 = Σ(xi − μ)2 / N

กลุ่มตัวอย่าง: s2 = Σ(xi − x̄)2 / (n − 1)

ส่วนเบี่ยงเบนมาตรฐาน (standard deviation): σ = √σ2, s = √s2 หน่วยเดียวกับข้อมูล

μ, N = ค่าเฉลี่ยและจำนวนข้อมูลของประชากร · x̄, n = ของกลุ่มตัวอย่าง

B: 2, 6, 10, 14, 18 (x̄ = 10): ระยะห่าง −8, −4, 0, 4, 8 → กำลังสองรวม 160 → s2 = 160 / 4 = 40, s ≈ 6.32 ส่วนชุด A ได้ s2 = 0.5, s ≈ 0.71

2.2.2.1 ทำไมกลุ่มตัวอย่างจึงหารด้วย n − 1

ข้อมูลอยู่ใกล้ x̄ ของตัวเองมากกว่าใกล้ μ เสมอ ผลรวมกำลังสองจึงต่ำกว่าที่ควรเป็น การหารด้วย n − 1 ชดเชยส่วนนี้ เรียกว่า การปรับแก้ของเบสเซล (Bessel's correction) ผลต่างจากการหารด้วย n เล็กลงเมื่อ n มาก

2.3 เลือกใช้ค่าสถิติให้เหมาะกับข้อมูล

ลักษณะข้อมูลค่ากลางค่าการกระจายเหตุผล
เชิงปริมาณ สมมาตร ไม่มีค่าผิดปกติค่าเฉลี่ยส่วนเบี่ยงเบนมาตรฐานใช้ข้อมูลครบทุกค่า
เชิงปริมาณ เบ้ หรือมีค่าผิดปกติมัธยฐานIQRไม่ถูกค่าสุดโต่งดึง
เรียงอันดับมัธยฐานIQR หรือพิสัยระยะห่างระหว่างอันดับไม่เท่ากัน
นามบัญญัติฐานนิยมไม่มีข้อมูลไม่มีลำดับ
  • รายงานค่ากลางคู่กับค่าการกระจายเสมอ
  • ค่าเฉลี่ยไวต่อค่าผิดปกติ มัธยฐานและ IQR ทนต่อค่าผิดปกติ
  • กลุ่มตัวอย่างหารด้วย n − 1 ประชากรหารด้วย N
  • สมมาตร: ค่าเฉลี่ยกับส่วนเบี่ยงเบนมาตรฐาน, เบ้: มัธยฐานกับ IQR
  • ค่ากลางสามแบบหาอย่างไร และแบบใดทนต่อค่าผิดปกติ 2.1
  • IQR คำนวณอย่างไร และเกณฑ์ค่าผิดปกติคืออะไร 2.2.1
  • สูตรความแปรปรวนของประชากรกับกลุ่มตัวอย่างต่างกันตรงไหน 2.2.2
  • เหตุใดกลุ่มตัวอย่างจึงหารด้วย n − 1 2.2.2.1
  • ข้อมูลเบ้ควรรายงานค่ากลางและค่าการกระจายคู่ใด 2.3
