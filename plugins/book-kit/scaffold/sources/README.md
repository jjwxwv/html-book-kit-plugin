# sources/ — วางไฟล์ต้นฉบับที่นี่

รองรับ: `.pdf`, `.md`, `.txt`, `.pptx`, `.docx`, `.html` และรูปภาพ (`.png`, `.jpg`) ไม่ต้องติดตั้งอะไรเพิ่มสำหรับ `.pptx`/`.docx`

**ตัวเลขนำหน้าโฟลเดอร์/ไฟล์คือสัญญาณลำดับบท** — kit ใช้เลขนี้สร้างโครงสร้างบท/หัวข้อย่อยหลายระดับ (เช่น `2`, `2.1`, `2.2.1`):

```text
sources/
├── ch1 - Introduction/
│   └── 1 intro slides.pptx
├── ch2 - Core Concepts/
│   ├── 2.1 overview.pdf
│   ├── 2.2 details.pdf
│   └── 2.2.1 pipelines.md          # หัวข้อย่อยของ 2.2
└── ch3 - Applications/
    └── 3 applications.pdf
```

กติกา:
- ชื่อโฟลเดอร์บทขึ้นต้นด้วย `ch<เลขบท>` หรือ `<เลขบท>` ก็ได้ (เช่น `ch2 - ...` หรือ `2 - ...`) เลขบทต้องเป็นจำนวนเต็ม
- **อย่าตั้งชื่อไฟล์ต้นฉบับว่า `readme.md`** — ไฟล์ชื่อนี้ถูกข้ามในทุกโฟลเดอร์ย่อย (ระบบสงวนชื่อนี้ไว้เป็นเอกสารกำกับ ไม่ใช่ต้นฉบับ) ถ้ามีให้เปลี่ยนชื่อเป็นแบบมีเลขนำหน้า เช่น `2.5 notes.md`
- ไฟล์ภายในขึ้นต้นด้วยเลขหัวข้อแบบจุด (`2.1`, `2.2.1`, ...) ถ้าไฟล์เดียวครอบคลุมทั้งบท ใช้เลขบทเฉยๆ (`2 ...`)
- ไฟล์เดียวกันอาจมีเนื้อหาซ้ำ/ทับซ้อนกับไฟล์อื่นได้ — ระบบจะ merge ให้เอง ไม่ต้องจัดการก่อน
- **`.pptx` / `.docx`:** ระบบอ่านข้อความ สมการที่พิมพ์ด้วย equation editor ตาราง ข้อมูลในกราฟ ข้อความใน SmartArt โน้ตผู้บรรยาย footnote และ endnote ได้ สิ่งที่อ่านไม่ได้คือ **รูปภาพ** และ object ฝัง (เช่น สมการแบบเก่า Equation Editor 3.0 / MathType) ระบบจะนับและ**แจ้งชื่อไฟล์ให้ทราบทุกครั้งที่ scan** ถ้าสไลด์สื่อความหมายหลักด้วยรูป ให้ export เป็น PDF มาวางแทน
- **ไฟล์ที่ไม่รองรับ** เช่น `.ppt`, `.doc`, `.xlsx` จะถูกแจ้งเตือนพร้อมวิธีแปลง และไม่ถูกนับเป็นเนื้อหาของหนังสือ
- **ไฟล์ยาว:** ระบบนับหน้า (PDF) สไลด์ (PPTX) และบรรทัด (DOCX, Markdown, text, HTML) เอง แล้วตรวจว่าถูกอ่านถึงท้ายไฟล์ ไม่ต้องติดตั้งอะไร ยกเว้น PDF ที่นับหน้าไม่ได้ (เช่น ไฟล์เข้ารหัส) ซึ่งระบบจะแจ้งและแนะนำ `pip install pypdf`
- แก้ไข/เพิ่ม/ลบไฟล์เมื่อไหร่ก็ได้ แล้วสั่ง `/book-kit:update-book` ระบบตรวจจับด้วย SHA-256 และทำเฉพาะส่วนที่กระทบ
- **ไฟล์ที่ไม่อยู่ในโฟลเดอร์บท** (เช่น `sources/misc/notes.md`) และไม่มีเลขนำหน้า ระบบไม่รู้ว่าเป็นของบทไหน จะแจ้งชื่อไฟล์ทุกครั้งที่ scan และให้ architect จัดลงบทตามเนื้อหา ถ้าต้องการกำหนดเอง ให้ย้ายไฟล์เข้าโฟลเดอร์บท
- **ลบบทกลางเล่ม:** ลบโฟลเดอร์ของบทนั้น แล้วเปลี่ยนเลขโฟลเดอร์และเลขไฟล์ของบทถัดไปให้ครบ ทำพร้อมกันในครั้งเดียวได้ ระบบเลื่อนเลขให้เอง
- **แทรกบทใหม่กลางเล่ม:** เปลี่ยนเลขโฟลเดอร์และเลขไฟล์ของบทที่อยู่ถัดไปให้ครบทั้งบท (เช่น `ch3 …` → `ch4 …`) แล้ววางบทใหม่ในเลขที่ว่าง ระบบจะเลื่อนเลขบท หัวข้อ และลิงก์ในหนังสือให้เองโดยไม่เขียนเนื้อหาใหม่

ห้ามให้ Claude แก้ไฟล์ในโฟลเดอร์นี้ (settings ตั้ง deny ไว้แล้ว) — ต้นฉบับเป็นของคุณเท่านั้น
